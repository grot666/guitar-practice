# 吉他练习 · Guitar Practice

在线使用：**https://grot666.github.io/guitar-practice/**

吉他入门练习工具，纯前端，部署在 GitHub Pages。没有后端和账号，声音只在你自己的浏览器里分析，练习记录只存在本机的 localStorage。

现在是第一阶段「熟悉吉他」：调准琴、认识第一把位、用单音弹几首简单的曲子。

## 四个模式

| 模式 | 做什么 |
|---|---|
| **调音** | 大字音名 + 音分指针。可以点某根弦锁定目标，同时播放参考音；选「自动」就显示最近的音。 |
| **练曲子** | 21 首公有领域的单音旋律，全部在第一把位（0–4 品），大多只用 1–3 弦。详见下面的「练曲子」一节。 |
| **认识指板** | 屏幕给出一个位置（或者只给音名），你弹出来，弹对了自动下一个。可以选范围：只弹空弦 / 1–3 弦 / 全部 6 弦，品格 0–3 或 0–4，12 个或 24 个。下面有一张第一把位音名表，点一下能听到这个音。 |
| **编曲入门** | 用 21 首曲子（4/4、弱起、3/4 都有）把一首歌拆成旋律、和弦、低音、鼓四层，一层一层开关着听，5 节小课各讲一个道理。详见下面的「编曲入门」一节。 |
| **节奏** | 节拍器（30–220 BPM，2/4、3/4、4/4，四分 / 八分 / 三连音 / 十六分），可以点拍子测速。「测一测」：先响 1 小节预备拍，再弹 4 小节，实时显示每一下早或晚多少毫秒，最后给出准确率、命中数、平均早晚和稳定性。 |

## 练曲子

练习界面：

- **滚动六线谱**：上面是 1 弦，数字是品格。音符块的长度表示时值，弹到的音会落到竖线上。
- **「现在弹」卡片**：大字显示位置（例如「2 弦 1 品」），也显示下一个音。点一下能听到这个音。
- **指板图**：实心点是当前音，虚线圈是下一个音。
- **「听到」**：显示麦克风听到的音，以及和目标差多少音分。
- 两种模式：
  - **等我**（默认）：弹对了才往下走，没有时间压力。弹错了会告诉你弹成了什么、应该弹哪里；偏高或偏低会显示差多少音分。
  - **跟拍**：先响 1 小节预备拍，然后跟着节拍器弹，同时评音准和节奏。
- **示范**：用合成的拨弦声按当前速度弹一遍，谱子跟着滚动。
- **速度**：40–160 BPM。
- **结束页**：
  - 1–3 颗星。
  - 「等我」模式给出一次弹对率、命中率和用时。
  - 「跟拍」模式给出音准、节奏和平均早晚。
  - 「要多练的位置」（最容易错的 3 个位置）和一句下一步的建议。

评分：

- **「等我」模式**：得分 = 0.5 × 一次弹对率 + 0.5 × 命中率。
- **「跟拍」模式**：
  - 每个音的判定窗口是音符时值的 15%–90%（已扣除校准的延迟）。窗口内至少 30% 的音高帧落在容差内，就算这个音弹对。
  - 节奏和节奏模式用同一套起音匹配和评分。
  - 得分 = 0.6 × 音准 + 0.4 × 节奏。
- **星级**：≥90% 三颗星，≥70% 两颗，≥40% 一颗。

**为什么没有《茉莉花》《樱花》**：

- 现在通行的《好一朵美丽的茉莉花》是何仿 1957 年在江苏民歌《鲜花调》基础上整理的版本，整理版本身是否还有版权有争议，先不收。
- 日本《さくら さくら》旋律是公有领域，但用的是都节音阶（A B C E F），和这一阶段的 I / IV / V 大调和弦不搭，以后讲小调、五声音阶时再加。

**为什么没有《四季歌》**：

- 常见的日本《四季の歌》是荒木とよひさ 1964 年的作品，还在版权期内。
- 中文《四季歌》是贺绿汀 1937 年改编的版本（贺绿汀 1999 年去世），也还在版权期内。

所以这两首都没有收进曲库。

### 曲库格式

曲子在 `js/songs.js` 的 `SONGS` 数组里，一首曲子一个对象：

```js
{
  id: 'twinkle',                 // 唯一 id，用在网址 #play/twinkle 里
  title: '小星星', en: 'Twinkle Twinkle Little Star',
  level: 1,                      // 难度 1–3
  bpm: 90,                       // 默认速度
  beats: 4,                      // 每小节拍数（3 = 3/4 拍）
  pickup: 0,                     // 弱起拍数（例如生日歌是 1）
  source: '……，公有领域',        // 来源，必须注明公有领域（测试会检查）
  tip: '……',                     // 练习提示
  notes: 'G3:1 G3:1 D4:1 D4:1 E4:1 E4:1 D4:2 ...',
}
```

`notes` 用空格分隔，每个记号的写法如下：

- `音名:拍数`，例如 `C4:1`（四分音符）、`D4:0.5`（八分音符）、`G3:1.5`（附点四分音符）。
- 休止符写成 `r:拍数`。
- 默认自动选指法：在 0–4 品里选最细的那根弦。要指定弦和品，就在后面加 `@弦-品`，例如 `D3:1@4-0`。

`tests/songs.test.mjs` 会检查每首曲子：

- 能正常解析，总拍数正好是整小节（扣除弱起）。
- 所有音都在第一把位（≤4 品），至少 85% 的音在 1–3 弦。
- 指法和音高一致，注明了公有领域。
- 开头几个音的音程和已知旋律一致（例如小星星的开头是 0 0 +7 0 +2 0 −2 半音）。

## 编曲入门

用的曲子：曲库里的 21 首全部可以编曲，按拍子分三组：

- **4/4 拍**：小星星、玛丽有只小羊羔、伦敦桥、欢乐颂、铃儿响叮当、热十字包、月光、洋基歌、两只老虎（轮唱曲，整首一个和弦）、小蜜蜂、王老先生有块地、送别。
- **4/4 拍 · 弱起**：圣者进行曲（弱起 3 拍）、哦！苏珊娜、康城赛马、红河谷（弱起 2 拍）、友谊地久天长。
- **3/4 拍**：新年好（克莱门汀）、奇异恩典、勃拉姆斯摇篮曲、生日歌。

**弱起**（曲子从小节中间开始，例如「Oh when the | saints」）：弱起的几个音单独显示在谱面上方，不配和弦；和弦、低音、鼓从下一小节的第 1 拍开始。**3/4 拍**：「低音+和弦」是华尔兹的「嘣-恰-恰」，分解和弦每小节 6 个八分音符，鼓每小节一个底鼓。

用到的和弦都是入门和弦：

- C 调：C、F、G、G7、Am。
- G 调：G、C、D、D7、Em。

**谱面**：

- 每小节一格，上面是和弦块，下面是旋律音。旋律音的高低位置跟着音高走。
- 旋律音是**实心**的，表示它在这一格的和弦里（和弦内音）；**空心**的就不在和弦里。
- 和弦块的颜色表示「贴合度」，也就是这一格的旋律有多少落在和弦里（按时长算，强拍上的音权重更大）：绿色 ≥75%，黄色 ≥40%，红色更低。
- 播放时有一条走动的播放线。
- 下面的「旋律 / 和弦 / 低音 / 鼓」开关在播放中也能随时切换，从当前小节开始马上就能听到变化。

5 节小课：

1. **旋律和伴奏**：依次听「只有旋律」→「＋一个持续低音（整首只弹主音）」→「＋和弦」→「＋低音和鼓」。
2. **和弦是怎么来的**：
   - 在大调音阶条上，从某个音开始隔一个取一个，就叠出 1-3-5。
   - 可以点 I / IV / V / vi / V7 看看、听听，同时显示吉他开放把位的按法。
3. **给旋律配和弦**：
   - 点和弦块按 I → IV → V → vi → V7 的顺序换和弦，会马上弹这一格给你听，颜色也会跟着变。
   - 可以先「全部用 I」从零开始，再和「推荐（自动配）」「参考答案」对比。
4. **伴奏型**：同样的和弦，换成长音、扫弦、分解和弦、低音+和弦四种弹法。
5. **速度与情绪**：
   - 欢快 = 快一点 + 扫弦。
   - 抒情 = 慢一点 + 分解和弦 + 把中间一些 I 换成 vi（关系小调和弦）。

**保存与导出**：

- 编好的和弦、伴奏型和速度保存在 localStorage（`guitar-practice:arrange`）。
- 「导出和弦谱」会生成文字和弦谱，例如 `| G | C G | C G | D G |`，并复制到剪贴板。

**乐理数据和算法**都在 `js/harmony.js`（纯函数，Node 里可以直接测试）：

- 和弦组成音、按法、播放音高。
- 调内和弦和每首曲子的参考和弦。
- 贴合度和自动配和弦（动态规划：贴合度高、少换和弦、首尾用 I、结尾前用 V 或 V7）。
- 伴奏型的播放事件表、导出和弦谱。

**声音**：都用 Web Audio 合成。旋律、和弦用 Karplus-Strong 拨弦，底鼓用正弦扫频，踩镲用高通噪声。

**低音**（`js/bass.js`，可以在编曲页选，旁边有「🔊 试听低音」）：

- **温暖电贝斯**（默认）：正弦基频 + 2～7 次谐波的加法合成，低通从 1.5 kHz 在 0.1 秒内降到 850 Hz（拨弦的「哇」→ 圆润），7 ms 柔和起音，衰减到持续电平，再轻微 tanh 饱和。
- **低音提琴拨弦**：同样的思路，衰减更快，低通更暗，加一点手指拨弦的「噗」声。
- **吉他低音弦**：Karplus-Strong 拨弦（阻尼更大、再过 1.3 kHz 低通），叠一点基频正弦。
- 音区是 E2–D#3（82–156 Hz）。手机扬声器基本放不出 150 Hz 以下，耳朵靠 2、3 倍频「脑补」音高，所以每种音色都保留了明显的 2、3 次谐波（温暖电贝斯约 −3 / −6 dB），2 kHz 以上压到 −40 dB 左右，不刺耳。
- 低音线：长音、分解和弦时每个和弦弹一个根音；扫弦、低音+和弦（4 拍一格）时弹「根音–五音」。
- 多层叠加时的音量：限幅器之前峰值 < 1（测试里离线混音整首验证），旋律最响，低音和和弦差不多。

以前的低音是把吉他拨弦合成直接降到 C2–B2，Karplus-Strong 在这么低的音高上只剩「嗡嗡」的噪声感，基频手机又放不出来，所以难听。

## 设置与测试面板

点右上角的 ⚙ 打开设置面板：手机上从底部弹出，电脑上从右侧滑出。所有调整都在面板里**当场就能看到效果**，不用切换页面：

- **检查清单**：麦克风已开启 / 听到了琴声 / 听到了节拍器 / 延迟已校准。
- **麦克风**：
  - 开关和输入设备选择。
  - 实时电平条，红线表示门限位置。
  - 实时音高读数；拨弦计数，检测到拨弦时会闪一下。
  - 自动或手动噪声门限、拨弦灵敏度。
- **声音输出**：
  - 外放、耳机、静音三种方式。
  - 节拍器音量，可以试听节拍器、播放参考音 A4。
- **延迟校准**：
  - 跟着 12 下「嘀」拨闷音。
  - 每检测到一下就在格子上亮起来，并显示这一下的毫秒数。
  - 结束后直接显示结果，也可以 ±5 ms 微调。
- **音准判定**：容差（±10–50 音分）、高低八度也算对、标准音 A4（430–450 Hz）。
- **外观**：深色 / 浅色 / 跟随系统。
- **数据**：导出或清空练习记录。

## 外放模式是怎么不把节拍器当成拨弦的

节拍器的「嘀」是 2.5–3.5 kHz 的纯音，起音和衰减都很平滑。外放模式下，起音检测跳过 2.1–4.3 kHz 和 7 kHz 以上的频段，所以嘀声和扬声器失真产生的谐波都不计入；吉他的基频和主要泛音在这个频段以外，照常检测。起音时间用 1.2 kHz 低通后的信号来细化。离线测试里，失真的外放嘀声在全频带检测下 4 下全被误判成拨弦，外放模式下误报为 0。

## 原理

- **音高：** McLeod Pitch Method（NSDF 归一化平方差 + 关键极大值 + 抛物线插值），窗口 2048 样本，约 25 帧/秒。显示用 5 帧中值平滑，换音（跳 >80 音分）时立即重置；声音停了以后保留上一个音 0.8 秒（变暗）。
- **自动门限：** 取最近约 10 秒块电平的第 5 百分位作为底噪，门限 = 底噪 + 12 dB（限制在 −65 到 −40 dB），实时更新。
- **起音：** 1024 点 FFT、hop 256 的对数幅度谱通量，自适应阈值（历史中位数 × 倍数 + 偏置）+ 峰值拾取 + 70 ms 去抖，并要求能量确实上升（排除手掌止音、音符结束时的频谱变化）。检测到之后，在附近按「后 128 样本能量 / 前 512 样本能量」最大的位置细化到约 16 样本（0.3 ms）。
- **时间轴：** 节拍器用 lookahead 调度（每 25 ms 预排 120 ms），直接排在 AudioContext 时间轴上。麦克风样本通过 AudioWorklet 带帧号传回，所以拨弦时间和拍点在同一条时钟上比较，不受主线程卡顿影响。
- **评分：** 起音和拍点一对一贪心匹配，窗口为 ±150 ms 和半个细分间隔中较小的那个。单下得分规则：≤20 ms 记满分，到 120 ms 线性降到 0。多弹的一下扣半拍分。

## 本地运行与测试

```powershell
# 任意静态服务器都行（麦克风要求 https 或 localhost）
python -m http.server 8000
# 打开 http://localhost:8000/

# 离线测试（Node 18+，无依赖）
npm test     # = dsp + songs + harmony + audio + bass 五组测试
```

- `tests/dsp.test.mjs`：用合成信号测试音高、起音、外放时的节拍器串音、手掌止音、节奏匹配、延迟估计和音准跟踪。
- `tests/songs.test.mjs`：测试曲库数据和指法，并逐音核对每首曲子开头的旋律。
- `tests/audio.test.mjs`：拨弦合成在 22.05 / 44.1 / 48 kHz 下的音高、直流和响度。
- `tests/bass.test.mjs`：三种低音音色在三种采样率下的音高、谐波（基频 + 2、3 次谐波）、2 kHz 以上的能量、起音时间、峰值、手机扬声器模型（250 Hz 4 阶高通）下的响度；再把整首编曲（旋律、和弦、低音、鼓，四种伴奏型 × 三种低音）离线混音，检查不削波、各层响度平衡。
- `tests/harmony.test.mjs`：测试和弦组成音（按法算出来的音必须和组成音一致）、调内和弦（音阶上 1-3-5 叠出来）、每首曲子的参考和弦（从 I 开始、在 I 结束、全在调内、贴合度 ≥70%）、自动配和弦（首尾用 I，和参考和弦至少 60% 相同），以及四种伴奏型的播放事件表（时间、数量、只用当前和弦里的音）、弱起（弱起里只有旋律，鼓和和弦从下一小节开始）、3/4 拍的「嘣-恰-恰」和低音线。

## 限制

- **手机没声音？** 先在设置面板点「🔈 测试声音」检查，然后依次排查：
  - 调大**媒体**音量。
  - iOS 16 及以下关掉静音拨片。
  - 只播放的时候关掉麦克风：iPhone 开着麦克风时会从听筒出声。编曲页和「示范」会自动关麦克风。
  - 微信等 App 的内置浏览器请改用 Safari 或 Chrome 打开。
  - 页面右下角出现「🔇 点一下开启」时点一下。
- **怎么保证有声：**
  - 每次点按都会在事件处理里同步解锁 AudioContext。
  - 没开麦克风时，iOS 17+ 把音频会话设为 `playback`；老 iOS 改用循环播放的静音 `<audio>`，这样静音拨片打开也能出声。
  - 切回前台时自动恢复。
- `tests/audio.test.mjs` 检查合成拨弦音在 22.05 kHz、44.1 kHz、48 kHz 下音高都准（误差 <3 音分）、没有直流、响度一致。
- 只识别**单音**音高，不能判断和弦。节奏模式里一次扫弦算一下。
- 延迟因设备而异，蓝牙耳机常见 150–300 ms，所以必须校准。蓝牙耳机的延迟还可能漂移，建议用有线耳机。
- 起音检测对**连奏**（击弦、勾弦、滑音）不灵敏。「等我」模式里同一个音连弹两次，需要重新拨弦，或者两次之间稍微停一下。
- 很吵的环境要调高噪声门限。iOS Safari 需要先点一下页面，声音才能启动。
- 现在只有第一把位和标准调弦。和弦、扫弦节奏型、更高把位留到后面的阶段。
