# 吉他练习 · Guitar Practice

在线使用：**https://grot666.github.io/guitar-practice/**

纯前端的吉他练习小工具，部署在 GitHub Pages。没有后端、没有账号，声音只在你自己的浏览器里分析，练习记录只存在本机的 localStorage。

## 功能

| 页面 | 做什么 |
|---|---|
| 调音 Tuner | 实时识别音高，显示音名、八度、频率和音分偏差指针。标准调弦 EADGBE，可锁定某根弦并播放参考音。 |
| 音准 Pitch | 按顺序弹一串目标音（空弦、C 大调、G 大调两个八度、E 小调五声、A 小调五声第 5 把位、单弦半音阶、自定义音符），每个音在 ±N 音分内算命中。统计命中率、一次命中率、平均音分偏差和偏高/偏低倾向。 |
| 节奏 Rhythm | 节拍器（30–240 BPM，2/4–6/8，四分/八分/三连音/十六分细分，重拍）。先数 1 小节预备拍，然后用麦克风检测每一下拨弦，和拍点比较：每下早/晚多少毫秒、命中率、平均绝对误差、倾向、稳定性（标准差）、漏拍、多余拨弦、准确率。 |
| 记录 History | 每次练习的结果和最近 30 次得分曲线，可导出 JSON 或清空。 |
| 设置 Settings | 延迟校准、A4 标准音（415–466 Hz）、自动/手动噪声门限、起音灵敏度、重新打开「三步开始」。 |

## 用法

第一次打开会出现「三步开始」卡片：

1. **允许麦克风。** 弹一下弦，电平条变绿、显示「🎸 听到了 E2」就说明收到了。
2. **试听节拍器、选输出方式。** 默认是「外放」（手机/电脑喇叭）；戴耳机就选「耳机」，检测更灵敏。听不到的话调大音量、关掉 iPhone 静音拨片。
3. **校准延迟。** 跟着 12 下「嘀」拨闷音，取中位数作为延迟补偿。之后的节奏误差都会扣掉这个延迟。

新手默认：节奏 70 BPM 四分音符 4 小节；音准练习从「空弦」开始，容差 ±30 音分。

### 外放模式是怎么不把节拍器当成拨弦的

节拍器的「嘀」是 2.5–3.5 kHz 的纯音，起音和衰减都很平滑。外放模式下，起音检测跳过 2.1–4.3 kHz 和 7 kHz 以上的频段，所以嘀声和扬声器失真产生的谐波都不计入；吉他的基频和主要泛音在这个频段以外，照常检测。起音时间用 1.2 kHz 低通后的信号来细化。离线测试里，失真的外放嘀声在全频带检测下 4 下全被误判成拨弦，外放模式下误报为 0。

## 原理

- **音高：** McLeod Pitch Method（NSDF 归一化平方差 + 关键极大值 + 抛物线插值），窗口 2048 样本，约 25 帧/秒。显示用 5 帧中值平滑，换音（跳 >80 音分）时立即重置；声音停了以后保留上一个音 0.8 秒（变暗）。
- **自动门限：** 取最近约 10 秒块电平的第 5 百分位作为底噪，门限 = 底噪 + 12 dB（限制在 −65 到 −40 dB），实时更新。
- **起音：** 1024 点 FFT、hop 256 的对数幅度谱通量，自适应阈值（历史中位数 × 倍数 + 偏置）+ 峰值拾取 + 70 ms 去抖，并要求能量确实上升（排除手掌止音、音符结束时的频谱变化）。检测到之后，在附近按「后 128 样本能量 / 前 512 样本能量」最大的位置细化到约 16 样本（0.3 ms）。
- **时间轴：** 节拍器用 lookahead 调度（每 25 ms 预排 120 ms），直接排在 AudioContext 时间轴上。麦克风样本通过 AudioWorklet 带帧号传回，所以拨弦时间和拍点在同一条时钟上比较，不受主线程卡顿影响。
- **评分：** 起音和拍点一对一贪心匹配，窗口为 ±150 ms 和半个细分间隔中较小的那个。单下得分规则：≤20 ms 记满分，到 120 ms 线性降到 0。多弹的一下扣半拍分。

## 本地运行与测试

```powershell
# 任意静态服务器都行（麦克风要求 https 或 localhost）
python -m http.server 8000
# 打开 http://localhost:8000/

# 离线算法测试（Node 18+，无依赖）
node tests/dsp.test.mjs
```

测试用合成信号检查以下内容：

- 正弦波和带谐波的音的音高
- Karplus-Strong 拨弦的音高
- 噪声下不误报
- 不同音高、同音快速重复、敲击、扫弦、弱拨的起音时间
- 外放时麦克风收到的节拍器声（含回声与削波失真）
- 手掌止音不被误判
- 节奏匹配和评分
- 延迟估计
- 音准练习跟踪器

## 限制

- 只识别**单音**音高。和弦不判断音高；节奏模式里一次扫弦算一下。
- 延迟因设备而异（蓝牙耳机常见 150–300 ms），必须校准；蓝牙耳机的延迟还可能漂移，建议用有线耳机。
- 起音检测对**连奏**（击弦、勾弦、滑音）不灵敏，因为这些没有明显的拨弦瞬态。
- 很吵的环境要调高噪声门限。iOS Safari 需要先点一下页面，声音才能启动。
- 不支持降调和其他调弦（音准练习可以用自定义音符代替）。
