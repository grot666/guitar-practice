# 吉他练习 · Guitar Practice

在线使用：**https://grot666.github.io/guitar-practice/**

吉他入门练习工具，纯前端，部署在 GitHub Pages。没有后端和账号，声音只在你自己的浏览器里分析，练习记录只存在本机的 localStorage。

现在是第一阶段「熟悉吉他」：调准琴、认识第一把位、用单音弹几首简单的曲子。

## 六个模式

| 模式 | 做什么 |
|---|---|
| **调音** | 大字音名 + 音分指针。可以点某根弦锁定目标，同时播放参考音；选「自动」就显示最近的音。 |
| **练曲子** | 21 首公有领域的单音旋律，全部在第一把位（0–4 品），大多只用 1–3 弦。详见下面的「练曲子」一节。 |
| **认识指板** | 屏幕给出一个位置（或者只给音名），你弹出来，弹对了自动下一个。可以选范围：只弹空弦 / 1–3 弦 / 全部 6 弦，品格 0–3 或 0–4，12 个或 24 个。下面有一张第一把位音名表，点一下能听到这个音。 |
| **编曲入门** | 用 21 首曲子（4/4、弱起、3/4 都有）把一首歌拆成旋律、和弦、低音、鼓四层，一层一层开关着听，5 节小课各讲一个道理。详见下面的「编曲入门」一节。 |
| **节奏训练** | 专门练节奏：15 个节奏型（四分、八分、十六分、三连音、附点、切分、休止、反拍、常用扫弦…），2/4、3/4、4/4、6/8。每一下早还是晚、早多少毫秒当场显示；练完自动诊断（抢拍 / 拖拍、稳定性、每个位置的统计、最差的位置），一键「专项练习」，自动调速。可以用内置节拍器，也可以跟另一台手机上的节拍器练。详见下面的「节奏训练」一节。 |
| **节拍器** | 节拍器（30–220 BPM，2/4、3/4、4/4，四分 / 八分 / 三连音 / 十六分），可以点拍子测速。「测一测」：先响 1 小节预备拍，再弹 4 小节，实时显示每一下早或晚多少毫秒，最后给出准确率、命中数、平均早晚和稳定性。 |

## 练曲子

练习界面：

- **滚动六线谱**：上面是 1 弦，数字是品格。音符块的长度表示时值，弹到的音会落到竖线上。
- **「现在弹」卡片**：大字显示位置（例如「2 弦 1 品」），也显示下一个音。点一下能听到这个音。
- **指板图**：实心点是当前音，虚线圈是下一个音。
- **「听到」**：显示麦克风听到的音，以及和目标差多少音分。
- 两种模式：
  - **等我**（默认）：弹对了才往下走，没有时间压力。弹错了会告诉你弹成了什么、应该弹哪里；偏高或偏低会显示差多少音分。
  - **跟拍**：先响 1 小节预备拍，然后跟着节拍器弹，同时评音准和节奏。
- **示范**：用合成的拨弦声按当前速度弹一遍，谱子跟着滚动。
- **速度**：40–160 BPM。
- **结束页**：
  - 1–3 颗星。
  - 「等我」模式给出一次弹对率、命中率和用时。
  - 「跟拍」模式给出音准、节奏和平均早晚。
  - 「要多练的位置」（最容易错的 3 个位置）和一句下一步的建议。

评分：

- **「等我」模式**：得分 = 0.5 × 一次弹对率 + 0.5 × 命中率。
- **「跟拍」模式**：
  - 每个音的判定窗口是音符时值的 15%–90%（已扣除校准的延迟）。窗口内至少两帧且占全部观测帧（含未检出音高）至少 30% 的帧落在容差内，就算这个音弹对。
  - 节奏和节奏模式用同一套起音匹配和评分。
  - 得分 = 0.6 × 音准 + 0.4 × 节奏。
- **星级**：≥90% 三颗星，≥70% 两颗，≥40% 一颗。

**为什么没有《茉莉花》《樱花》**：

- 现在通行的《好一朵美丽的茉莉花》是何仿 1957 年在江苏民歌《鲜花调》基础上整理的版本，整理版本身是否还有版权有争议，先不收。
- 日本《さくら さくら》旋律是公有领域，但用的是都节音阶（A B C E F），和这一阶段的 I / IV / V 大调和弦不搭，以后讲小调、五声音阶时再加。

**为什么没有《四季歌》**：

- 常见的日本《四季の歌》是荒木とよひさ 1964 年的作品，还在版权期内。
- 中文《四季歌》是贺绿汀 1937 年改编的版本（贺绿汀 1999 年去世），也还在版权期内。

所以这两首都没有收进曲库。

### 曲库格式

曲子在 `js/songs.js` 的 `SONGS` 数组里，一首曲子一个对象：

```js
{
  id: 'twinkle',                 // 唯一 id，用在网址 #play/twinkle 里
  title: '小星星', en: 'Twinkle Twinkle Little Star',
  level: 1,                      // 难度 1–3
  bpm: 90,                       // 默认速度
  beats: 4,                      // 每小节拍数（3 = 3/4 拍）
  pickup: 0,                     // 弱起拍数（例如生日歌是 1）
  source: '……，公有领域',        // 来源，必须注明公有领域（测试会检查）
  tip: '……',                     // 练习提示
  notes: 'G3:1 G3:1 D4:1 D4:1 E4:1 E4:1 D4:2 ...',
}
```

`notes` 用空格分隔，每个记号的写法如下：

- `音名:拍数`，例如 `C4:1`（四分音符）、`D4:0.5`（八分音符）、`G3:1.5`（附点四分音符）。
- 休止符写成 `r:拍数`。
- 默认自动选指法：在 0–4 品里选最细的那根弦。要指定弦和品，就在后面加 `@弦-品`，例如 `D3:1@4-0`。

`tests/songs.test.mjs` 会检查每首曲子：

- 能正常解析，总拍数正好是整小节（扣除弱起）。
- 所有音都在第一把位（≤4 品），至少 85% 的音在 1–3 弦。
- 指法和音高一致，注明了公有领域。
- 开头几个音的音程和已知旋律一致（例如小星星的开头是 0 0 +7 0 +2 0 −2 半音）。

## 编曲入门

用的曲子：曲库里的 21 首全部可以编曲，按拍子分三组：

- **4/4 拍**：小星星、玛丽有只小羊羔、伦敦桥、欢乐颂、铃儿响叮当、热十字包、月光、洋基歌、两只老虎（轮唱曲，整首一个和弦）、小蜜蜂、王老先生有块地、送别。
- **4/4 拍 · 弱起**：圣者进行曲（弱起 3 拍）、哦！苏珊娜、康城赛马、红河谷（弱起 2 拍）、友谊地久天长。
- **3/4 拍**：新年好（克莱门汀）、奇异恩典、勃拉姆斯摇篮曲、生日歌。

**弱起**（曲子从小节中间开始，例如「Oh when the | saints」）：弱起的几个音单独显示在谱面上方，不配和弦；和弦、低音、鼓从下一小节的第 1 拍开始。**3/4 拍**：「低音+和弦」是华尔兹的「嘣-恰-恰」，分解和弦每小节 6 个八分音符，鼓每小节一个底鼓。

用到的和弦都是入门和弦：

- C 调：C、F、G、G7、Am。
- G 调：G、C、D、D7、Em。

**谱面**：

- 每小节一格，上面是和弦块，下面是旋律音。旋律音的高低位置跟着音高走。
- 旋律音是**实心**的，表示它在这一格的和弦里（和弦内音）；**空心**的就不在和弦里。
- 和弦块的颜色表示「贴合度」，也就是这一格的旋律有多少落在和弦里（按时长算，强拍上的音权重更大）：绿色 ≥75%，黄色 ≥40%，红色更低。
- 播放时有一条走动的播放线。
- 下面的「旋律 / 和弦 / 低音 / 鼓」开关在播放中也能随时切换，从当前小节开始马上就能听到变化。

5 节小课：

1. **旋律和伴奏**：依次听「只有旋律」→「＋一个持续低音（整首只弹主音）」→「＋和弦」→「＋低音和鼓」。
2. **和弦是怎么来的**：
   - 在大调音阶条上，从某个音开始隔一个取一个，就叠出 1-3-5。
   - 可以点 I / IV / V / vi / V7 看看、听听，同时显示吉他开放把位的按法。
3. **给旋律配和弦**：
   - 点和弦块按 I → IV → V → vi → V7 的顺序换和弦，会马上弹这一格给你听，颜色也会跟着变。
   - 可以先「全部用 I」从零开始，再和「推荐（自动配）」「参考答案」对比。
4. **伴奏型**：同样的和弦，换成长音、扫弦、分解和弦、低音+和弦四种弹法。
5. **速度与情绪**：
   - 欢快 = 快一点 + 扫弦。
   - 抒情 = 慢一点 + 分解和弦 + 把中间一些 I 换成 vi（关系小调和弦）。

**保存与导出**：

- 编好的和弦、伴奏型和速度保存在 localStorage（`guitar-practice:arrange`）。
- 「导出和弦谱」会生成文字和弦谱，例如 `| G | C G | C G | D G |`，并复制到剪贴板。

**乐理数据和算法**都在 `js/harmony.js`（纯函数，Node 里可以直接测试）：

- 和弦组成音、按法、播放音高。
- 调内和弦和每首曲子的参考和弦。
- 贴合度和自动配和弦（动态规划：贴合度高、少换和弦、首尾用 I、结尾前用 V 或 V7）。
- 伴奏型的播放事件表、导出和弦谱。

**声音**：都用 Web Audio 合成。旋律、和弦用 Karplus-Strong 拨弦，底鼓用正弦扫频，踩镲用高通噪声。

**低音**（`js/bass.js`，可以在编曲页选，旁边有「🔊 试听低音」）：

- **温暖电贝斯**（默认）：正弦基频 + 2～7 次谐波的加法合成，低通从 1.5 kHz 在 0.1 秒内降到 850 Hz（拨弦的「哇」→ 圆润），7 ms 柔和起音，衰减到持续电平，再轻微 tanh 饱和。
- **低音提琴拨弦**：同样的思路，衰减更快，低通更暗，加一点手指拨弦的「噗」声。
- **吉他低音弦**：Karplus-Strong 拨弦（阻尼更大、再过 1.3 kHz 低通），叠一点基频正弦。
- 音区是 E2–D#3（82–156 Hz）。手机扬声器基本放不出 150 Hz 以下，耳朵靠 2、3 倍频「脑补」音高，所以每种音色都保留了明显的 2、3 次谐波（温暖电贝斯约 −3 / −6 dB），2 kHz 以上压到 −40 dB 左右，不刺耳。
- 低音线：长音、分解和弦时每个和弦弹一个根音；扫弦、低音+和弦（4 拍一格）时弹「根音–五音」。
- 多层叠加时的音量：限幅器之前峰值 < 1（测试里离线混音整首验证），旋律最响，低音和和弦差不多。

以前的低音是把吉他拨弦合成直接降到 C2–B2，Karplus-Strong 在这么低的音高上只剩「嗡嗡」的噪声感，基频手机又放不出来，所以难听。

## 节奏训练

节奏是熟练工：**弹 → 马上知道每一下早了还是晚了 → 练完看哪里最差 → 慢下来专门练那里 → 稳了自动加速**，一直循环。这个页面就是按这个循环做的。只看「什么时候拨弦」，不看音高：弹哪根弦、闷音都行。

**练的时候（界面只有这些）：**

- 上面是节奏型的格子：一小节分成若干格，亮的格子要弹，↓↑ 是建议的拨弦方向，下面是数拍子的念法（1 和 2 和 / 1 e 和 a / 1 2 3）。你弹一下，对应的格子会闪绿 / 黄 / 红。
- 大字：这一下「早 18 ms」「晚 42 ms」「正好」，以及是第几拍的哪个位置。
- 偏差条：标记左右移动，中间绿色、两边黄色、再外面红色（区间宽度就是你设的容差）。
- 小节图：当前小节里每个音一个槽，点画在槽的左边 = 早、右边 = 晚（放大显示，±150 ms 占满半个槽）；没弹到的音结算后打 ×，多弹的画成灰点。
- 每结算一小节，下面出现一个小方块：小节号、得分，变绿表示「达标」（没漏、没多弹、每一下都在黄色以内），↑↓ 表示自动调了速度。

**练完的诊断：**

- **倾向**：平均偏差。平均早 ≥12 ms 算「抢拍」，晚 ≥12 ms 算「拖拍」。
- **稳定性**：偏差的标准差。<15 ms 很稳，<30 ms 还行，再大就是忽早忽晚。
- **每个位置**：一小节里每个位置（第 1 拍、第 1 拍后半、第 2 拍…）单独统计平均早晚、离散、漏了几次，画成柱状图。
- **最差的位置**和建议；如果同一种位置全都差（比如每一拍的后半都晚），会合并成一个问题：「问题集中在每拍后半」。
- **专项练习**：一键用 85% 的速度再练，最差的位置在格子里用黄框标出；练完显示这些位置专项前后的对比。
- **趋势**：最近 16 次的准确率曲线、这个节奏型最快达标的速度、稳定性的变化。全部存在 localStorage。

**设置（都在同一页的「练习设置」里，不用切页面）：**

| 项目 | 选项 |
|---|---|
| 拍号 | 2/4、3/4、4/4、6/8（6/8 的 BPM 按附点四分算，一小节两大拍，节拍器会轻响八分） |
| 节奏型 | 四分；八分；四分 + 休止；反拍八分（拍上休止）；三连音；十六分；八分 + 两个十六分；附点八分 + 十六分；切分（八分-四分-八分）；扫弦「下 下上 上下上」「下 下上 下 下上」（4/4）、「下 下上 下上」（3/4）；6/8 的六个八分、附点四分、长-短 |
| 小节数 | 4 / 8 / 16 / 32（另加 1 小节预备拍） |
| 节拍器响哪几下 | 每拍 / 只响 2、4 拍（3/4 是「嗯 嚓 嚓」）/ 只响第 1 拍 |
| 隔小节静音 | 每 Y 小节静 X 小节：静音的小节节拍器不响、拍点也不闪，但照样打分，练心里的拍子 |
| 细分点 | 八分 / 三连 / 十六分的轻「嘀」 |
| 自动调速 | 连续 N 小节（1–4）达标 +4 BPM；连续 2 小节没达标 −4 BPM（最多退回起始速度 −12）；新速度从下一小节开头生效 |
| 容差 | 绿色 ±10–50 ms，黄色 ±30–120 ms |
| 声音反馈 | 准「叮」、偏了「咚」（频率放在外放模式会忽略的频段里，不会被当成拨弦） |
| 节拍来源 | 内置节拍器 / 外部节拍器（见下） |

**判定规则：** 每个期望的音和你的拨弦一对一匹配，按误差从小到大贪心配对；匹配窗口 = min(150 ms, 相邻两个音间隔的一半)。窗口外的拨弦算「多弹」，没配上的音算「漏」。单个音得分：绿 1、黄 0.6、红 0.25、漏 0；准确率 = 总分 ÷（音数 + 0.5 × 多弹数）。

### 设备延迟：自动测，不测人

以前的校准是「听节拍器、跟着拨」，测出来的其实是**你的反应**，不是设备延迟。现在改成**回环自动测**：

1. 喇叭放 8 下很短的扫频「啾」（1.5→6 kHz，10 ms），间隔随机（0.5–0.8 秒）。
2. 麦克风同时录音（关闭了回声消除、降噪和自动增益）。
3. 录音先高通 1.2 kHz（去掉琴声、人声），再和「啾」的波形做互相关（FFT），取包络。
4. 8 下的相关包络叠加：只有真实延迟处 8 下同时对齐（间隔是随机的，回声和别的声音对不上），找到峰值后再逐下细化到亚毫秒，并检查波形相关系数（宽带噪声、拨弦对不上）。
5. 取中位数作为延迟，用 MAD 估计离散度：≥6 下且离散 ≤2 ms 为「可信度高」，≤5 ms 为「中」，否则「低」（不采用）。听不清时不改原来的值，并提示调大音量、别戴耳机、保持安静，也可以 ±5 ms 手动调。

测出来的是「喇叭出声 + 麦克风收音」的总延迟：你听到「嘀」就弹，琴声到程序里要晚这么多，所以打分时把它扣掉。设置面板和节奏训练页里都能测。

### 外部节拍器

可以用另一台手机上的节拍器 App 当拍子：

- **测试（设置面板 →「外部节拍器测试」，或节奏训练的「先听 8 秒测一下」）：** 只听不弹，显示测到的 BPM、每一下的抖动（相对拟合网格的均方根偏差）和最大偏差。能测出「很稳」，说明麦克风和起音检测在你的设备上工作正常——跟人无关。
- **跟外部节拍器练：** 节拍来源选「外部节拍器」，速度可以自动检测或手动填写。点「开始」后先别弹：程序听到 6 下规律的「嗒」（抖动 <12 ms）就锁定拍子网格，数 1 小节预备，然后开始打分。内置节拍器不响。
- **怎么把「嗒」和你的拨弦分开：** ① 规律——锁定后，节拍器的声音落在网格上（±35 ms 以内）；② 音色——拨弦在 1 kHz 以下的能量会突然上升很多，节拍器的「嗒」主要是高频。锁定时记下节拍器的低频上升量，之后落在网格上、低频上升不超过它 2.5 倍的才算节拍器，其余都是你的拨弦。每听到一下节拍器就微调相位和速度（锁相环），节拍器略快或略慢也跟得住。
- 节拍器和琴声走同一个麦克风，延迟相同，所以外部节拍器模式**不需要延迟校准**。
- **限制：** 节拍器每拍只能响一下（6/8 拍每个附点四分响一下）；不要开重音以外的细分。节拍器的声音要比琴声小、放在 30–50 cm 外。你的拨弦如果在「嗒」之后 35 ms 以内，会和「嗒」合成一个起音，时间按「嗒」算（显示偏早一点）。如果节拍器本身的声音低频很重（比如木鱼、鼓声音色），可能被当成拨弦，换成「滴答」类高音色。外部模式下不能自动调速（速度由那台节拍器决定）。

## 开发者模式：记录并导出诊断日志

练习时如果音高经常听错（比如二弦一品的 C4 显示成 C2）、或者改了容差却感觉判定不对，可以自己录一份诊断日志发给开发者。入口在右上角 ⚙ **设置与测试** 面板里的「**开发者模式**」，练习过程中随时能打开，不必离开当前页面。

**怎么用：**

1. 打开设置面板，在「开发者模式」里点 **开始记录日志**。顶栏会出现红色的「记录中」指示（显示已用时间和事件条数）。只有正在记录时才会显示「记录中」。
2. 按平时那样复现问题（例如弹二弦一品、改容差再弹、或跑一段节奏训练）。
3. 点 **停止记录**。日志会留在本机，直到你开始新的记录或点「清空日志」。
4. 点 **导出日志**，得到一份 JSON 文件，把它发给开发者即可。正在记录时也可以导出，导出的是到目前为止的内容，记录会继续。

**日志里有什么：** 开始时的设置快照和之后的改动（容差、标准音、八度选项等）、浏览器与 AudioContext 采样率、麦克风轨道的非标识设置（回声消除 / 降噪是否关闭、采样率等，**不含设备名和 deviceId**）、麦克风开关和错误、练习模式和当前目标音、节流后的检测结果（频率、MIDI、音分、清晰度、电平，以及掉音）、音准判定（含容差、是否做了八度折回、原始音分）、节奏训练每一下的早晚和小节结算、运行时错误。

**不会有什么：** 默认不录原始声音；不会上传到任何服务器；没有设备名、设备 ID 或其它密钥。导出文件开头有中文说明。日志有条数和时长上限（约 4000 条或 15 分钟），超出后会自动停止，文件里会标明截断和丢弃条数，避免把手机卡住。

如果浏览器不能下载文件，会尝试打开系统分享，或把 JSON 复制到剪贴板，并明确告诉你发生了什么。换用 Safari / Chrome 一般可以正常下载。


## 外放模式是怎么不把节拍器当成拨弦的

节拍器的「嘀」是 2.5–3.5 kHz 的纯音，起音和衰减都很平滑。外放模式下，起音检测跳过 2.1–4.3 kHz 和 7 kHz 以上的频段，所以嘀声和扬声器失真产生的谐波都不计入；吉他的基频和主要泛音在这个频段以外，照常检测。起音时间用 1.2 kHz 低通后的信号来细化。离线测试里，失真的外放嘀声在全频带检测下 4 下全被误判成拨弦，外放模式下误报为 0。

## 单音识别与回放验证

`js/recognition.js` 的 PitchRecognizer 接收单声道浮点 PCM、音频块起始秒数、线性 RMS 门限和帧回调。实时麦克风和 Node 离线回放共用这个入口。每帧记录窗口中心的音频时间，raw 供练习评分，freq 和短时保持的 show 供显示。目标音只进入练习判定。指定音高练习区分 E2 和 E4；只看音名或开启八度宽容时才忽略八度。

真琴验收可在设置中开始记录，指定一弦空弦 E4 后先弹六弦 E2，再弹一弦 E4。严格模式应依次判错、判对；打开八度宽容后两者均可命中。开发者日志 pitch 提供 audioTime、gate、status（voiced / below_gate / unresolved），score 提供目标与判定；跟拍还记录 observed（窗口观测数）、frames（有音高数）、good、need 和 reason。日志只有测量摘要，无法从中重建录音。单独录制一个已知音高（每个文件一个音，单声道 16-bit PCM WAV），运行 `node tools/replay-pitch.mjs take.wav E2`。命令按 A4=440 Hz、固定 RMS 门限 0.005 回放，输出总帧、有音高帧、±30 音分内的帧、错八度帧，以及从文件开头到第一帧命中的秒数。前后静音计入总帧。

## 原理

- **音高：** McLeod Pitch Method（NSDF 归一化平方差 + 关键极大值 + 抛物线插值），窗口 2048 样本，约 25 帧/秒。显示用 5 帧中值平滑，换音（跳 >80 音分）时立即重置；声音停了以后保留上一个音 0.8 秒（变暗）。
- **自动门限：** 取最近约 10 秒块电平的第 5 百分位作为底噪，门限 = 底噪 + 12 dB（限制在 −65 到 −40 dB），实时更新。
- **起音：** 1024 点 FFT、hop 256 的对数幅度谱通量，自适应阈值（历史中位数 × 倍数 + 偏置）+ 峰值拾取 + 70 ms 去抖，并要求能量确实上升（排除手掌止音、音符结束时的频谱变化）。检测到之后，在附近按「后 128 样本能量 / 前 512 样本能量」最大的位置细化到约 16 样本（0.3 ms）。
- **时间轴：** 节拍器用 lookahead 调度（每 25 ms 预排 120 ms），直接排在 AudioContext 时间轴上。麦克风样本通过 AudioWorklet 带帧号传回，所以拨弦时间和拍点在同一条时钟上比较，不受主线程卡顿影响。
- **评分：** 起音和拍点一对一贪心匹配，窗口为 ±150 ms 和半个细分间隔中较小的那个。单下得分规则：≤20 ms 记满分，到 120 ms 线性降到 0。多弹的一下扣半拍分。

## 限制

- **手机没声音？** 先在设置面板点「🔈 测试声音」检查，然后依次排查：
  - 调大**媒体**音量。
  - iOS 16 及以下关掉静音拨片。
  - 只播放的时候关掉麦克风：iPhone 开着麦克风时会从听筒出声。编曲页和「示范」会自动关麦克风。
  - 微信等 App 的内置浏览器请改用 Safari 或 Chrome 打开。
  - 页面右下角出现「🔇 点一下开启」时点一下。
- **怎么保证有声：**
  - 每次点按都会在事件处理里同步解锁 AudioContext。
  - 没开麦克风时，iOS 17+ 把音频会话设为 `playback`；老 iOS 改用循环播放的静音 `<audio>`，这样静音拨片打开也能出声。
  - 切回前台时自动恢复。
- `tests/audio.test.mjs` 检查合成拨弦音在 22.05 kHz、44.1 kHz、48 kHz 下音高都准（误差 <3 音分）、没有直流、响度一致。
- 只识别**单音**音高，不能判断和弦。节奏模式里一次扫弦算一下。
- 延迟因设备而异，蓝牙耳机常见 150–300 ms，所以必须校准。蓝牙耳机的延迟还可能漂移，建议用有线耳机。
- 自动测延迟要求麦克风能听到喇叭：戴耳机时测不了（耳机里的声音传不到麦克风）。可以先用外放测，或者手动 ±5 ms；外接蓝牙耳机后的延迟只能手动调，或者用外部节拍器模式（不需要校准）。
- 部分手机 / 浏览器即使关闭了回声消除，系统仍会处理麦克风信号，测试音可能被削弱；这时会提示「没听清」，换个浏览器或调大音量再试。iPhone 开着麦克风时声音从听筒出来，音量小，可以把手机放平、靠近一点。
- 起音检测本身有几毫秒的偏差（合成信号测试里约 +3 ms）；这个偏差对每一下都一样，不影响「哪里早、哪里晚」的判断。

- 现在只有第一把位和标准调弦。和弦、扫弦节奏型、更高把位留到后面的阶段。
